# Team Stress Management Assistant

To run the chatbot, you need the projekt_wytwor folder and a Python environment with the libraries listed in requirements.txt.
After activating the virtual environment and installing the required libraries, launch the application from the Command Prompt using the command "streamlit run app.py".
After about 10 seconds, a browser window with the local app interface should appear.
